# 班级朗读记录系统

一个轻量的 PHP + MySQL 班级晨读 / 晚读打卡系统，供班干部在早读、晚读时段快速记录全班朗读情况，并按日 / 周 / 月 / 学期统计排行。

## 功能

- 密码登录，Session 鉴权
- 早读 / 晚读两种记录类型，仅在指定时间段内开放操作
- 学生卡片一键「+ 加分 / − 扣分」，点击即时反馈（波纹动画 + 底部提示），不等服务器回传
- 一次朗读时间最多加一分（加分后本次锁定），扣分不限
- 已记录卡片盖绿色「优秀」印章，有扣分待补齐的卡片盖红色「差」印章；重复加分弹出醒目弹窗提示
- 统计页支持今日 / 本周 / 本月 / 学期排行，含净分、百分比与正分分布饼图
- 数据表在首次访问统计页时自动创建

## 界面

「纸墨 · 印章」主题：米白纸面、墨黑通栏、朱红印章点缀；已记录卡片盖绿色「优秀」印章，有待补扣分的卡片盖红色「差」印章，移动端自适应。

## 部署

1. 环境要求：PHP 8.x + MySQL（PDO 扩展）。
2. 复制配置模板并填写真实信息：

   ```bash
   cp config.example.php config.php
   ```

   在 `config.php` 中填写数据库连接、登录密码与学生名单。
3. 将全部文件上传到站点目录，访问 `index.php` 即可；首次访问 `stats.php` 会自动建表。

## 文件结构

| 文件 | 说明 |
|---|---|
| `config.example.php` | 配置模板（真实 `config.php` 含密码，不入库） |
| `functions.php` | 鉴权、时段判断、记录 / 扣分 / 统计等核心逻辑 |
| `index.php` | 登录页与打卡记录页 |
| `stats.php` | 排行榜与饼图统计页 |
| `style.css` | 全站样式（纸墨 · 印章主题） |
